## 1.1 Сравнение LLM-моделей

|                                    | Локальные Hugging Face                                                                                                        | Облачные OpenAI / YandexGPT              |
|------------------------------------|-------------------------------------------------------------------------------------------------------------------------------|------------------------------------------|
| Качество ответов                   | Среднее                                                                                                                       | Наилучшее                                |
| Скорость работы                    | Низкая/Средняя (зависит от доступных ресурсов компании)                                                                       | Высокая                                  |
| Стоимость владения и использования | Низкая/Средняя (может потребовать значительных вложений на старте, зависит от свободных ресурсов компании на момент запуска) | Высокая (необходимо следить за токенами) |

### 1.3 Сравнение векторных баз

|                                 | FAISS                                                                         | ChromaDB                                                                                        |
|---------------------------------|-------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------|
| Скорость поиска и индексации    | Сверхбыстрая in-process (C++) (требует переиндексации при обновлении данных)  | Очень быстрая in-process, скейл ограничен RAM (не требует переиндексации при обновлении данных) |
| Сложность внедрения и поддержки | Является стандартом Де-факто для первых экспериментов с векторным поиском     | Быстрый старт, удобное API, интеграция с LangChain                                              |
| Удобство в работе               | Рекомендуется для PoC                                                         | Медленнее FAISS, имеет ограничения на больших больших объемах данных, фильтрации по метаданным  |


### 1.4 Рекомендуемая конфигурация сервера

- CPU: 16 ядер (Intel Xeon)
- RAM: 64 GB
- GPU: NVIDIA RTX 4090 
- Storage: 1 TB SSD
- Network: 1 Gbps


## Варианты архитектурных решений

### Локальное развёртывание

- LLM: Llama
- Эмбеддинги: Sentence-Transformers
- Векторная БД: FAISS
- Приватность: Полный контроль над конфиденциальной информацией
- Стоимость: На старте потребуется сервер из пункта 1.4 выше, далее расходы минимальны  

### Облачное развёртывание

- LLM: OpenAI GPT-4
- Векторная БД: Qdrant Cloud
- Приватность: Риск утечки  
- Стоимость: Достаточно сложно контролировать расходы, могут достигать $1000+ 

### Итоговая рекомендация

Рекомендуется развернуть стек локально. 
Критические поинты:
- Полный контроль над конфиденциальной информацией.
- Возможность реализации PoC с минимальными финансовыми вложениями.
- Более низкие финансовы затраты в далёкой перспективе.
